Enable pushing logs to your storage service, <GlossaryTooltip term="SIEM">SIEM solution</GlossaryTooltip>, or log management provider.

:::note
Logpush does not send from a fixed or published set of IP addresses. Traffic originates from Cloudflare's network (ASNs 13335, 132892, and 202623), but source addresses are not guaranteed to fall within the ranges listed at [Cloudflare IPs](https://www.cloudflare.com/ips/) and may change without notice. An allowlist built from that list can block Logpush traffic, including the validation request sent when a job is created.

To secure your destination, authenticate incoming requests instead, for example with a secret token in a request header. For HTTP destinations, use `header_*` URL parameters to set the header. If your destination must restrict traffic by source IP, use [Dedicated Egress IPs for Cloudflare Logpush](/logs/logpush/logpush-job/enable-destinations/egress-ip/).
:::
